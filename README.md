# Brutalist-Light Editorial Personal Brand Website

## Overview
This project explores a **Brutalist-Light Editorial design system** applied to a high-conversion personal brand website for creators.

The goal is not just to build a visually distinct interface, but to experiment with how **raw, structured design** can still drive **clarity, usability, and conversion**.

This is an **experimental frontend project** focused on:
- breaking away from generic SaaS UI patterns  
- building a reusable, system-driven design approach  
- balancing bold aesthetics with practical usability  

---

## ✦ Core Idea
Modern web design is often:
- overly polished  
- rounded and safe  
- visually repetitive  

This project intentionally moves in the opposite direction:

→ sharp edges  
→ visible structure  
→ high-contrast layouts  
→ editorial-style composition  

While still maintaining:
→ readability  
→ responsiveness  
→ real-world usability

## 🎨 Design System Highlights

### 1. Brutalist Structure
- 0px border radius (strict rule)
- 2px visible borders across components
- hard offset shadows (no blur)

### 2. Color Philosophy
- Neutral base: `#f7f9fd`
- Structural layers: `#eceef2`
- Accent (CTA): Neon Lime `#bff365`
- High contrast dark elements

### 3. Typography
- Headings: Space Grotesk (bold, impactful)
- Body: Inter (clean and readable)
- Strong hierarchy and editorial feel

### 4. Layout Approach
- asymmetry over centered layouts  
- strong grid influence  
- intentional “dead space”  
- section separation using lines instead of shadows
